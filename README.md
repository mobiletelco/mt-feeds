# mt-feeds

Generated RSS feeds for sites that block normal feed readers.

- `gadgets360-hindi.xml` - Gadgets360 Hindi news (hindi.gadgets360.com/news),
  rebuilt every 30 minutes by GitHub Actions (`.github/workflows/gadgets360-feed.yml`).

Feed URL for readers: https://raw.githubusercontent.com/mobiletelco/mt-feeds/main/gadgets360-hindi.xml
